# 📚 教程指南模板 (Viral Edition)

**适用场景**：步骤教学、配置指南、最佳实践、工具搭建  
**目标字数**：1000-2000字  
**核心目标**：学完即用 + 避免踩坑

---

## 输入变量

```yaml
tutorial_goal: "读者学完能达成什么目标"
prerequisites: ["前置条件1", "前置条件2"]
steps_overview: "整体步骤概览（3-5步）"
key_commands: "关键命令/代码"
common_pitfalls: ["坑1", "坑2", "坑3"]
expected_result: "最终效果描述"
time_estimate: "预计耗时"
```

---

## Prompt 模板

```markdown
你是一位AI效率领域的 viral content creator。
请基于以下素材，撰写一篇爆款教程：

【目标】{{tutorial_goal}}
【前提】{{prerequisites}}
【步骤概览】{{steps_overview}}
【核心命令】{{key_commands}}
【常见坑点】{{common_pitfalls}}
【最终效果】{{expected_result}}
【耗时】{{time_estimate}}

要求：

1. 标题（4选1公式）：
   - 《[X分钟]搞定[复杂任务]，手把手教学》
   - 《为什么你的[配置]总是失败？（附完整步骤）》
   - 《从0到1搭建[系统]，我只用了[时间]》
   - 《这个[工具]配置，让我省了[X小时/天]》

2. 开头2句（必须爆）：
   - 结果前置："看完这篇文章，你只需要[X分钟]，就能[达成目标]。"
   - 或痛点共鸣："你是不是也被[常见问题]折磨过？今天一次性解决。"
   - 或数字冲击："我踩了[X个坑]，花了[Y小时]，只为让你[省时间]。"

3. 小标题（全部爆炸性）：
   - 不用"准备工作"，改用"《开始前，你需要这3样东西》"
   - 不用"步骤一"，改用"《第1步：[具体动作]（[预计时间]）》"
   - 不用"常见问题"，改用"《这3个坑，90%的人都会踩》"
   - 不用"总结"，改用"《下一步：如何[进阶/优化]？》"

4. 内容结构：
   - 引子（钩子：结果前置）
   - 前置条件（必须清单）
   - 核心步骤（每步配截图/命令）
   - 坑点预警（红色警示）
   - 效果验证（如何确认成功）
   - 进阶建议（下一步做什么）

5. 步骤规范：
   - 每步都有编号和预计时间
   - 关键命令用代码块，可复制
   - 截图配文字说明（圈出关键位置）
   - 每步结束有"验证方法"

6. 图片要求：
   - 每步至少1张截图
   - 关键配置界面全屏截图
   - 最终结果展示图
   - 错误提示截图（坑点部分）

7. 结尾（必须有）：
   > 如果教程对你有帮助，点个⭐收藏！
   > 
   > 遇到问题？在评论区描述现象，我会回复。
   > 
   > 想看[进阶主题]的教程？告诉我！

语气：像耐心的学长/学姐，手把手教，不跳步，不装逼。
```

---

## 示例输出

**标题**：《5分钟搭建个人AI助手，从零到上线完整指南》

**开头**：
> "只需要5分钟，你就能拥有一个24小时在线的AI助手。不需要服务器，不需要写代码，跟着做就行。"

**小标题**：
- 《开始前，你需要这3样东西》
- 《第1步：安装OpenClaw（2分钟）》
- 《第2步：配置API密钥（1分钟）》
- 《这2个坑，新手最容易踩》
- 《验证：给你的助手发第一条消息》
