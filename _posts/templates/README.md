# 📝 博客模板使用指南

## 快速开始

每次想写文章时，只需告诉我：

```
我要写一篇[文章类型]，素材如下：
- 核心事件：XXX
- 关键发现：XXX
- 技术细节：XXX（技术类）/ 使用感受：XXX（体验类）
```

## 文章类型对应表

| 你想表达的内容 | 使用模板 | 触发词 |
|---------------|---------|--------|
| 开源项目/代码实现 | 技术深潜 | "技术深潜" / "项目总结" |
| AI/工具使用感受 | 体验手记 | "体验手记" / "使用体验" |
| 教学/步骤指南 | 教程指南 | "教程" / "指南" / "How to" |
| 行业观察/思考 | 思考碎片 | "思考" / "观点" / "随笔" |

## 模板特色

✅ **爆款标题公式** - 数字+反常识 / 痛点+解决方案  
✅ **黄金开头2句** - 冲突式/悬念式钩子  
✅ **爆炸性小标题** - 每段都有点击欲  
✅ **自动配图提示** - 代码截图/架构图/演示GIF  

## 文件清单

- `style-guide.md` - 全局风格规范
- `prompt-viral-tech.md` - 技术深潜（爆款版）
- `prompt-viral-experience.md` - 体验手记（爆款版）
- `prompt-viral-tutorial.md` - 教程指南（爆款版）
- `prompt-viral-thought.md` - 思考碎片（爆款版）
