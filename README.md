# SoSME's Lab

个人技术网站，使用 Jekyll + GitHub Pages 构建。

## 网站地址
https://fjmw123.github.io

## 本地开发

```bash
# 安装依赖
bundle install

# 本地运行
bundle exec jekyll serve

# 访问 http://localhost:4000
```

## 项目结构

```
├── _config.yml          # 网站配置
├── _layouts/            # 页面模板
├── _includes/           # 可复用组件
├── _posts/              # 博客文章
├── _sass/               # SCSS样式
├── assets/              # 静态资源
├── pages/               # 独立页面
└── index.html           # 首页
```

## 功能特性

- ✅ 深色/浅色模式切换
- ✅ 响应式设计
- ✅ 项目展示
- ✅ 博客系统
- ✅ 代码高亮
- ✅ RSS订阅

## 部署

推送到 GitHub 后自动部署到 GitHub Pages。
